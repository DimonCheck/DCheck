    📝 Как добавить новую статью
Откройте data/posts.json

Добавьте новый объект в массив posts:

json
{
    "id": "unikalnyy-id",
    "title": "Название статьи",
    "date": "2026-08-02",
    "preview": "Краткое описание...",
    "content": "<p>Полный текст...</p>",
    "tags": ["тег1", "тег2"],
    "readingTime": 3
}
Сохраните файл — статья появится на сайте автоматически!
